# Kite v0.6.85

Kite v0.6.85 packages the current workspace changes on top of the merged
release history.

## Changes

- Open column search from keyboard input using the last hovered or operated column.
- Update column search results live and highlight matching names.
- Include the current workspace's Windows, macOS, archive, preview, and updater changes.

## Install

- Windows: use `Kite-v0.6.85-windows-x64.zip` or the standalone `Kite.exe`.
- macOS: use `Kite-v0.6.85-macOS-arm64.zip` on Apple Silicon.
- Verify downloads with `SHA256SUMS.txt`.
