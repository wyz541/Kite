# Kite v0.6.87

- Windows and macOS: Edit Markdown and see unsaved changes rendered in a second pane in the same window. The pane can be hidden. Supports `.md`, `.markdown`, `.mdx`, and `.mk`. Live preview does not load images and pauses for documents over 256 KiB.
- Windows: Preview mind-map and Office package content, and edit supported XML or JSON source in a separate window. Office preview is text-only; PowerPoint scope is the first slide. SVG supports image preview and source editing. PNG and JPEG are preview-only.

## Install

- Windows: use `Kite-v0.6.87-windows-x64.zip` or the standalone `Kite.exe`.
- macOS: use `Kite-v0.6.87-macOS-arm64.zip` on Apple Silicon.
- Verify downloads with `SHA256SUMS.txt`.
