# Kite v0.6.84

Kite v0.6.84 improves keyboard-driven column search on macOS and Windows.

## Changes

- Typing in the column view opens search in the last hovered or operated column.
- The active column search field receives keyboard focus after it opens.
- `Ctrl+F` on Windows and `Command+F` on macOS focus the correct column search field.
- The search bar has a clearer compact field, integrated close action, and focused border state.
- The result count and truncation indicator stay visible while the search field is open.

## Install

- Windows: use `Kite-v0.6.84-windows-x64.zip` or the standalone `Kite.exe`.
- macOS: use `Kite-v0.6.84-macOS-arm64.zip` on Apple Silicon.
- Verify downloads with `SHA256SUMS.txt`.
