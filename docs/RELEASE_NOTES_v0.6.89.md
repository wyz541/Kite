# Kite v0.6.89

## Workspace editor

- Windows: add a toolbar entry for a directory-based workspace editor with a VS Code/Obsidian-style tree, refresh, collapse/expand, and file selection.
- Windows and macOS: preview and edit supported text, Markdown/.mk, image, Office, and mind-map formats through the existing preview/editor surfaces.
- Built-in kite.markdown plugin: Markdown live preview, editing, outline, backlinks, tasks, and wikilinks capability manifest.
- Windows: protect workspace traversal from symlink loops and keep local packages valid when optional Kensaku sidecars are omitted.
- macOS parity: the workspace tree opens the existing text editor window; embedded editor panes remain a follow-up.

## Install

- Windows: use Kite-v0.6.89-windows-x64.zip or the standalone Kite.exe.
- macOS: use Kite-v0.6.89-macOS-arm64.zip on Apple Silicon.
- Verify downloads with SHA256SUMS.txt.
