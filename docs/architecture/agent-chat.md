# Agent 对话与任务控制

## 结论

Agent 栏使用共享 Agent Runtime 驱动对话。
Windows 与 macOS 不直接管理 Agent 子进程，只展示结构化快照并发送用户动作。
运行时、协议、权限和诊断由 Rust Core 负责。

## 工作目录解析

工作目录由 Core 的 `WorkingDirectoryPolicy` 解析，UI 不在 Windows 与 macOS 各复制一套推断逻辑。
右键预填、状态条展示和 `AgentRuntime::start` 使用同一个解析结果；运行时在启动子进程前会再次校验，
避免状态展示与实际 cwd 分叉。

| 策略 | 解析规则 |
| --- | --- |
| `SelectedItem` | 目录目标使用目录本身；文件目标使用文件父目录 |
| `FileParent` | 文件使用父目录；目录目标降级为其父目录，文件系统根目录保持自身 |
| `RepositoryRoot` | 从主目标向上解析 Git worktree 根目录；非仓库直接报错 |
| `Fixed` | 每次启动前校验绝对路径、目录存在且可访问；失效时阻止启动并提供设置入口 |
| `Ask` | 发送前打开目录选择步骤；未选择时不会启动，也不会回退到临时目录或调用方默认值 |

主目标负责策略解析，附加上下文路径不会改变已经解析的工作目录。工作目录策略修改后，当前面板会重新解析；
如果新策略无效，发送会被阻止，不会静默使用旧目录。

## 输入与快捷键

- 输入区支持多行编辑。
- `Enter` 发送，`Shift+Enter` 换行。
- 运行中禁止重复发送。
- 发送按钮和停止按钮使用稳定命令入口，便于键盘与辅助技术访问。
- 输入内容在发送前保持可检查状态。

## 任务状态

`AgentRuntimeState` 映射为以下用户状态：

| Runtime 状态 | 用户状态 |
| --- | --- |
| `Starting` | 启动中 |
| `Initializing` | 握手中 |
| `Ready` | 已就绪 |
| `Running` | 运行中 |
| `WaitingPermission` | 等待权限 |
| `Cancelling` | 取消中 |
| `Completed` | 完成 |
| `Failed` | 失败 |
| `Cancelled` | 已取消 |
| `Closed` | 已关闭 |

同一 Agent 任务只允许一个活动 Runtime。
旧 Runtime 进入完成、失败、取消或关闭状态后，面板才允许再次发送或重试。

## 流式回答

- `MessageChunk` 增量写入 Markdown 输出视图。
- Windows 使用异步 Markdown `TextViewState`，不在 UI 线程等待解析。
- macOS 使用 Markdown 解析后的原生 Text 与流式更新。
- 输出达到 Core 上限时保留可恢复内容，并显示截断提示。
- 复制只复制当前可恢复内容，不伪造已丢弃的文本。

## 自动跟随

- 新输出到达时，如果自动跟随开启，回答区域滚动到最新位置。
- 用户向上滚动后关闭自动跟随。
- 出现“回到最新”按钮；用户显式点击后恢复自动跟随。
- 自动跟随状态不会影响 Runtime，也不会停止任务。

## 停止与重试

- 运行中始终提供“停止”动作。
- 停止通过 Runtime 取消整个任务，而不是仅隐藏 UI。
- 失败、取消或完成后保留上一条提示。
- “重试”使用同一上下文和上一条提示启动新的 Runtime。
- 重试失败时保留错误信息与设置入口。

## 错误与诊断

- 未安装、未认证、协议不兼容、超时、取消和内部错误使用不同恢复提示。
- 错误卡提供重试或 Agent 设置入口。
- 原始 stderr 不进入对话正文。
- 诊断日志通过独立的脱敏诊断入口查看。
- 权限请求显示允许、本任务允许、拒绝和取消任务动作。

## 生命周期

- 任务由 Core 持有，不随 Agent 栏隐藏或独立窗口关闭而停止。
- 返回 Agent 栏或重新打开独立窗口时读取同一 Runtime 快照。
- 文件导航、预览切换和分栏操作在任务运行期间保持可用。
