# Kite Agent 表面

## 结论

Kite 把 Agent 作为外部工作能力的宿主。
主窗口右侧区域在“预览”和“Agent”之间切换。
Agent 也可以弹出为独立窗口。
右侧栏和独立窗口共享同一个 Agent 表面状态，不创建两份上下文。

本阶段只交付布局、上下文快照、弹出和路由。
发送、流式输出、权限确认和文件修改不在本阶段范围内。

## 布局

- 分栏仍占据主工作区。
- 右侧区域默认显示预览。
- Agent 打开后保留分栏导航，不把对话页签混入文件页签。
- 右侧栏提供“预览 / Agent”切换、关闭和在独立窗口中打开。
- 窄窗口使用覆盖式抽屉，分栏不被压缩到不可用宽度。
- 抽屉仍提供添加上下文、移除和发送准备控件。

## 上下文快照

右键文件或文件夹时，Kite 生成明确的主目标、附加路径和工作目录。
Agent 默认使用固定快照。
切换目录不会静默改变固定快照。
只有显式开启“跟随当前选择”后，Kite 才更新上下文。

文件目标默认使用父目录作为工作目录。
目录目标默认使用自身。
多选路径完整进入快照，右键目标仍作为主目标。

上下文条显示每个路径。
用户可以移除路径、定位到分栏，或通过路径选择器追加文件和目录。
发送前必须能看到 Agent、模型、工作目录、权限和连接状态。

## 会话状态

共享状态覆盖以下阶段：

- 空白：还没有上下文。
- 未配置：上下文已准备，但没有 Agent 接入。
- 加载：正在连接。
- 运行中：已连接并可承载任务。
- 错误：连接或协议失败。
- 已结束：任务结束但结果仍可查看。

当前实现只启用空白和未配置状态。
后续任务通过同一状态模型开启加载、运行、错误和结束状态。

## 独立窗口

独立窗口直接渲染与右侧栏相同的 Agent 实体。
因此移除上下文、切换跟随模式或追加路径会同步反映在两个载体中。
关闭独立窗口不会复制或销毁会话。
会话继续保留在主窗口的 Agent 表面中。

## 路由

- 右键菜单只负责生成启动请求并打开 Agent 表面。
- 右键不会改变分栏选择，也不会加载下一分栏。
- “配置 Agent…”进入设置中的 Agent 页面。
- 空状态可以直接进入 Agent 设置。
- 定位操作复用主窗口分栏导航。

## 非目标

- 不启动模型运行时。
- 不自动发送预填提示。
- 不流式渲染 Markdown。
- 不自动应用补丁。
- 不绕过权限确认执行命令。

## 验证

- 文件目标使用父目录作为默认工作目录。
- 目录目标使用自身。
- 固定快照不随选择变化。
- 跟随模式随选择更新。
- 主目标和附加路径可移除、定位和追加。
- 右侧栏与独立窗口共享同一状态。
- 窄窗口以覆盖抽屉显示 Agent。
- 空状态可进入 Agent 设置。
