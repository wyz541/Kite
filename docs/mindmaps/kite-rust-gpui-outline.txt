Kite × Rust GPUI 工程沉淀
	01 项目定位与边界
		产品定位
			本地优先的跨平台原生文件管理器
			分栏导航、预览、搜索、文件操作在同一工作区
		架构定位
			共享 Rust Core
			Windows：Rust + GPUI
			macOS：SwiftUI + AppKit
			两端共享领域能力，不共享 UI 渲染器
		设计原则
			macOS 作为视觉与交互基准
			Windows GPUI 实现同一产品语义
			路径先于装饰，状态先于品牌，反馈先于动画
			可逆性优先：历史、回收站、会话恢复、确认
		核心能力来源
			[文档] README.md：产品、功能、构建与总体架构
			[文档] docs/design/manifesto.md：项目宪法与反模式
			[文档] docs/architecture/platforms.md：双原生 UI 边界
			[配置] Cargo.toml：包描述、features 与平台依赖

	04 GPUI 编程模型
		Entity 与 Context
			Entity<T>：可观察状态对象
			Context<T>：update / notify / spawn / subscribe
			cx.new：创建子 Entity
			this.update / this.update_in：异步结果回到 UI
		Render
			用 Rust 组合元素树
			render 读取最新状态
			条件组合：when / when_some
			子窗口通过 Entity 嵌入元素树
		Element DSL
			div / h_flex / v_flex
			flex_1 / w_full / h_full / min_w_0
			gap / padding / border / rounded / overflow
			bg / text_color / theme token
		组件库
			Button / Switch / Progress
			Input / Textarea / Editor / TextView
			DataTable / TableDelegate
			PopupMenu / DropdownMenu / ContextMenuExt
			ScrollableElement / Scrollbar / Resizable
		交互模型
			actions! 宏声明命令
			key_context 与 focus_handle
			on_action / capture_key_down / listener
			Entity observation / EventEmitter / Subscription
		核心能力来源
			[框架] GPUI：Entity、Context、Render、Task、Subscription
			[框架] gpui-kit component：Button、Input、DataTable、Menu、Scroll
			[代码] src/actions.rs、src/app.rs、src/table.rs
			[代码] src/tabs.rs：observe + EventEmitter + Subscription
	05 状态模型与数据流
		状态所有权
			KiteWindow：页签集合、活动页签、共享剪贴板
			KiteApp：单页签导航、列表/分栏、搜索、预览、Git、Agent 编排
			子 Entity：InputState、TableState、AgentPanel
			Rust Core：领域状态、持久化、外部进程与索引
		状态分组
			导航：current_dir / history / history_index
			列表与分栏：TableState / column_panes / selection
			反馈：loading / error / notice / skipped
			异步协调：generation / Task / cancel flag
			工作流：modal / git_dialog / active_git_operation / Agent
			持久化：session / ui_preferences / favorites
		标准数据流
			用户输入 → Action / listener
			修改 KiteApp 或子 Entity 状态
			需要 I/O 时创建 Task
			background_spawn 执行阻塞工作
			await 后在 update/update_in 中回写
			generation 校验过期结果
			cx.notify 触发 Render
		跨实体观察
			KiteWindow observe KiteApp
			页签变化更新窗口标题和会话
			TabRequest 事件解耦页签命令
			共享剪贴板通过 Rc<RefCell<...>> 在页签间复用
		核心能力来源
			[框架] Entity / Context / Render / observe / subscribe
			[代码] src/app.rs：KiteApp 状态字段与状态变更
			[代码] src/tabs.rs：KiteWindow 和页签同步
			[代码] src/session.rs、src/ui_preferences.rs、src/favorites.rs
	06 异步、并发与性能
		Task 生命周期
			Task 存入结构体字段以保证存活
			替换或丢弃 Task 会取消旧任务
			Task::ready(()) 用于清空
			.detach() 用于明确的后台独立任务
		任务分工
			cx.spawn / cx.spawn_in：UI 协程
			cx.background_spawn：阻塞式文件、搜索、Git 工作
			await 后回到 foreground 更新 Entity
			window.defer：延后到当前更新之后
		取消与防旧结果
			load_generation
			search_generation / column_search_generation
			vcs_generation / column_generation / preview_generation
			AtomicBool 搜索取消标记
			VCS CancellationToken
		防抖与节流
			预览加载防抖
			分栏搜索防抖
			目录变化自动刷新防抖
			全局名称查询延迟
		性能保护
			后台索引低优先级
			结果数量与输出长度上限
			图片预览缓存容量
			perf_trace 首内容渲染标记
			性能 JSON 基线与对照
		核心能力来源
			[框架] Task、cx.spawn、cx.spawn_in、background_spawn、window.defer
			[标准库] std::sync::atomic、mpsc、Arc、Mutex
			[代码] src/file_watcher.rs、src/content_search.rs、src/name_index.rs
			[代码] src/perf_trace.rs
			[文档] docs/architecture/auto-refresh.md、docs/performance/README.md

	14 共享 Rust Core 与跨语言边界
		Core 约束
			不依赖 GPUI / SwiftUI / AppKit
			领域规则、状态机、持久化和副作用收敛
			UI 只做输入适配、调用编排和展示
		UniFFI 边界
			Record：跨语言数据传输
			Enum：稳定状态与错误分类
			Object：可持有服务、任务和监视器
			Callback interface：Git 事件与凭据回调
		Core API
			CoreRequest / CoreResult / CoreError
			ExecutionContext
			trace_id / deadline / idempotency_key
			read_only / confirmed
			Tool / Resource / Prompt 注册
		多端入口
			GPUI UI
			SwiftUI UI
			kite-cli
			kite-mcp
		核心能力来源
			[库] uniffi 0.32.2
