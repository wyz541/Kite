# Kite v0.6.83

Kite v0.6.83 adds keyboard-driven search for the active column.

## Changes

- Windows and macOS remember the last column visited by the cursor or used by selection.
- Printable keyboard input opens that column's search field automatically.
- Windows supports `Ctrl+F`; macOS supports `Command+F` and `Control+F`.
- Column search updates while the user types, highlights all matching results, and navigates to the first result.
- macOS temporary-directory search tests now handle canonical paths consistently.

## Install

- Windows: use `Kite-v0.6.83-windows-x64.zip` or the standalone `Kite.exe`.
- macOS: use `Kite-v0.6.83-macOS-arm64.zip` on Apple Silicon.
- Verify downloads with `SHA256SUMS.txt`.
